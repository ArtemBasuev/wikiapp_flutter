# WikiApp

Приложение-каталог на Flutter: список статей Википедии с поиском и подгрузкой, экран статьи, светлая и тёмная тема, интерфейс на русском и английском. Данные приходят из сети.

## Предметная область

Каталог статей английской Википедии. Данные берутся из MediaWiki Action API (`https://en.wikipedia.org/w/api.php`), того же источника, что в ЛР1. Моков в приложении нет.

Поля статьи (`ArticleModel`):

| Поле | Что это |
|---|---|
| `id` | номер статьи |
| `title` | название |
| `extract` | вводный абзац обычным текстом |
| `url` | адрес статьи в Википедии |
| `length` | размер статьи в байтах |
| `touched` | дата последней правки (UTC) |
| `categories` | названия категорий |
| `links` | названия связанных статей (только на экране статьи) |

Что умеет приложение:

- список всех статей по порядку названий с самого начала, следующие страницы подгружаются при прокрутке;
- поиск по запросу, при пустом результате экран «Ничего не найдено»;
- экран статьи: загружается отдельным запросом, со всеми категориями и первыми десятью ссылками на другие статьи; связанные статьи загружаются параллельно;
- индикатор загрузки, а при ошибке сообщение и кнопка «Повторить» (список, подгрузка и экран статьи);
- переключение темы и языка кнопками в шапке (по умолчанию язык системы или браузера). Переводится интерфейс, тексты статей остаются как есть.

## Данные и сеть

Цепочка слоёв: API-клиент → датасорс → репозиторий → Cubit или Bloc → экран.

```
lib/
  common/network/        dio_client.dart (адрес, таймауты, общие параметры),
                         load_exception.dart (виды ошибок загрузки)
  features/article/data/
    api/                 ArticleApi: запросы к серверу
    dto/                 DTO ответа (json_serializable)
    data_sources/        датасорс: ошибки dio превращаются в LoadException
    mappers/             DTO → модель ArticleModel
    article_repository.dart
```

- Базовый адрес сервера записан один раз, в `DioClient`. Туда же вынесен параметр `origin=*`: без него браузер отбрасывает ответ из-за CORS.
- Cubit и Bloc знают только `LoadException`: про `dio` и DTO выше датасорса никто не знает.
- Сгенерированные `*.g.dart` лежат в git. Если менять DTO, их нужно пересоздать:

```
dart run build_runner build --delete-conflicting-outputs
```

## Запуск

Нужен установленный Flutter и доступ в интернет. Проверить окружение можно командой `flutter doctor`.

```
flutter pub get
flutter run -d chrome
```

`flutter pub get` обязателен после клонирования: он генерирует код локализации (`lib/l10n/app_localizations*.dart`), в git он не лежит.

Второй таргет, на выбор:

| Платформа | Что нужно | Команда |
|---|---|---|
| Windows | Visual Studio 2022, workload «Desktop development with C++» | `flutter run -d windows` |
| macOS | Xcode | `flutter run -d macos` |
| Android | Android Studio, SDK, эмулятор или телефон | `flutter run -d <id>` |

Список доступных устройств и их `<id>`: `flutter devices`. Вместо `chrome` можно использовать `edge`.

Для сети на macOS нужно разрешение `com.apple.security.network.client` в файлах `macos/Runner/*.entitlements`, на Android в release-сборке разрешение `INTERNET` в манифесте. В debug-сборке на Android оно уже есть.

Проверка ARB:

```
dart run tool/check_arb.dart
```
